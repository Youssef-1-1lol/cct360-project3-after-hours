# Expressive Interfaces requirements

Recorded from the Quercus assignment inspected November 25, 2026. Course 440555, assignment 1821263. Due December 2, 2026 at 1 p.m.; individual work, 20 points.

- Experimental interface communicates an idea through interaction, motion and behaviour.
- 4–6 distinct states/scenes. After Hours plans five: arrival, noise, sorting, boundary, quiet.
- At least three dynamic behaviours: message dismissal, thought sorting, threshold-driven atmosphere and personalized ending.
- Two unconventional navigation/reveal mechanisms: rotary entry and swipe-away notifications; drag/drop sorting provides an additional interaction.
- At least two animations/transitions: scene entry and message exit, with reduced-motion support.
- Responsive layout.
- Live GitHub Pages URL and repository URL; ZIP containing HTML, CSS, JavaScript and assets.
- 5–7 slides covering overview, interaction/navigation, technical features, visual design, rationale, references, and both URLs.
- Five-minute recorded presentation.
- Prepare for a possible 2–3-minute in-class code walkthrough.
